Rogi_Nav_Documentation documentation
====================================

Rogi Nav は、ロボコン向けの ROS 2 ナビゲーションスタックです。
Gazebo シミュレーション、LiDAR センシング、地図変換、自己位置推定、
経路追従、BehaviorTree による状態管理、RViz/Groot/Web 表示をまとめて起動できます。
